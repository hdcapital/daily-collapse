# Watchlist notes (example data-lake file)

Drop your own broker notes, memos, screeners etc. in this folder (or point the
scanner at S3 via the DATALAKE_S3_BUCKET secret). Any text file mentioning a
ticker code gets fed to the AI as context when that stock crashes.

Example entry:

XYZ — Been watching since the FY25 result. Balance sheet thin; they'll need to
raise before December. If it gaps down hard, check for a placement announcement
first.
